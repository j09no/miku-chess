# Miku Chess

Boss vs **Miku** - chess with voice, emotions and attitude.

**Play:** https://j09no.github.io/miku-chess/

- Elo selector: 400 / 800 / 1200 / 1600 / 2000
- Side select (White/Black), Mood: Soft / Normal / Savage
- Click a piece -> legal moves + capture probability %
- Click an enemy piece -> threat report (attackers / defenders / victims)
- Victim red glow + danger mode pulse
- Miku talks: game start voice bank + live TTS with emotion (pitch/rate)
- Live chat - Miku replies in text AND voice
- Undo / Resign / PGN export

Fully client-side, zero dependencies, zero servers.
